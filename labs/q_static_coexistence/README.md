# Q fusion and static-scale coexistence

Status: integrated and CPU-green; static activation artifact pending.

This bundle records the audited source/test patches that added static
out-projection to the promoted Q path and extended every static consumer with
the five-attribute plan-owned hook certificate. The finalized postimages are
also present directly in `integration/comfyui/` and the static labs.

Before Q/K mutation, static Q requires a complete bridge, exact scale object,
exact plan hook IDs, the H3 7,168 -> 5,376 output projection, and all existing
owner/runtime/patch/shape guards. A static miss after attention may execute
stock out-projection once; it cannot select dynamic quantization and cannot
rerun attention. With no static bridge the already-qualified dynamic
supplied-amax route remains unchanged.

The frozen audit passed 153 pytest cases plus 15 unittest subtests. The real
plan lifecycle test covers publication, cross-consumer use, foreign-hook
rejection, pre-existing-hook suppression, and restoration.
